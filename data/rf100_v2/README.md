# RF100 Construction Safety v2

The primary benchmark uses 1,206 images from RF100 Construction Safety v2. Download the original images from:

https://universe.roboflow.com/roboflow-100/construction-safety-gsnvb

The images are not redistributed here. `labels/` contains the manually reviewed and refined three-class annotations used in the paper; these labels are more than an automatic class conversion. `manifest.tsv` maps each public label file to its upstream image identity and split, while `mapping.tsv` records the class mapping. Exact primary membership is in `data/primary_benchmark/`.
